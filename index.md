# Vibe Coding Webinar: Example App Gallery

This page collects working examples of small web apps built with generative AI and natural-language prompting. Each example includes a live, browser-based demo and the GitHub repository containing the source code. The examples are intended to show how quickly practical tools, prototypes, and teaching demonstrations can be created through vibe coding.

## Webinar Slides

The main presentation slides for the webinar are available here:

[Open webinar slides](https://gdsaxton.github.io/vibe-coding-webinar-slides/)

These slides were also built as a browser-based web app, demonstrating how generative AI can be used not only to create tools and calculators, but also to build custom presentation materials.
